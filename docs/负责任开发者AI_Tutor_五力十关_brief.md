# AI5000天 · 负责任开发者 AI Tutor
## 五力十关成长路径 · 产品 Brief

**一句话定位**：面向 12-18 岁的个人化 AI 创客训练系统。它不是聊天机器人，也不是低代码工具，而是一条"负责任创新的标准之路"——孩子从真实数智风险出发，走完五力十关，完成一次真正负责任的 AI 创造。

---

## 一、我们要做什么

**目标人群**：12-18 岁儿童青少年，分两版覆盖。

**产品要交付的三件事**：

1. **可复玩**：不是走一次就结束的课程，而是想创新时就能反复调用的标准动作。
2. **灵活创新**：允许不同入口、不同议题、不同项目类型，孩子的创造不被路径框死。
3. **推行我们的标准**：把"负责任的开发者""伦理 in 设计开发过程""社区关切·技术向善"这套理念，做成孩子必经的创新协议。

**核心定位——【创"心"标准】**：我们要打造的是，任何人想创新的时候，都得走这条路、用这个框架。十关不是一门课，是**负责任创新的标准动作**。因为它是标准而非课程，"再来一局"就是带着新议题在更高档位上再走一遍——可复玩性由此天然成立，不靠人为堆难度。

---

## 二、五力序列（锁定）

```
安全力觉醒 → 实感力锻造 → 脑波力启蒙 → 创心力迸发 → 沟通力绽放
```

流程逻辑：先看见风险、锁定责任议题（**安全**）→ 把议题落回真实故事、挖透根源（**实感**）→ 拆解议题背后的 AI 机制、准备人机协作（**脑波**）→ 构建可运行方案（**创心**）→ 放大影响、发布成果（**沟通**）。

真实问题（安全 + 实感）始终排在 AI 工具（脑波 + 创心）之前，"**问题先于工具**"由此自然成立。导航、进度、徽章、数据标签、状态机全部按此序列绑定。

---

## 三、双版同构：一套标准，两个档位

**同一套十关骨架，人人走通。**

| 版本 | 年龄 | 定位 | 差异落点 |
| --- | --- | --- | --- |
| **青年版** | 15-18 | 完整硬版：真开发、真机制、真两难 | 第 5、6、8、9 关做满 |
| **少年版** | 12-14 | 减负同构：同样十关，降低技术与认知负荷 | 第 5、6、8、9 关减负 |

**原则**：少年版是青年版的**减负同构**，不是另一套东西。标准只有一套，孩子长大了在同一条路上换更高的档。第 1-4 关、第 7 关、第 10 关两版共用；差异只落在四个"硬"关（见第六节对照）。

## 五、关卡详解（青年版）

### 【安全力觉醒】

**第1关 · 小伍风险冒险局**
目的：让孩子认识数字风险，并发现自己真正关心的风险。
流程：
1. 选择入口——推荐 或 自带点子：
   - 推荐：填写自己对五大风险的了解度 → 选择感兴趣的风险议题 → 机器推荐卡牌
   - 自带点子：填写自己的点子 → 填写自己对五大风险的了解度 → 机器推荐卡牌
2. 答题 6~7 张卡牌，查看评分与复盘。
3. 点击 31 个议题或自填，收敛出自己最关心的 3 个问题。
产出：关心问题 Top 3

**第2关 · 责任议题锁定**
目的：从 3 个问题中选定一个责任议题——不是选"最优议题"，而是选一个"我担得起、走得动"的议题。
五维自评（第一人称"我足够…"，1-5 自评）：

| 维度 | 自评句 | 含义 |
| --- | --- | --- |
| 共振 | 我足够被这个议题触动 | 它是我真的在意的，不是随便选的 |
| 责任 | 我足够愿意为这个议题担起责任 | 我愿意做点什么，而不只是抱怨 |
| 原创 | 我足够想用自己的方式去做 | 我有自己的想法，不是照抄别人 |
| 嵌入 | 我的议题足够嵌入到社会真切需要的地方 | 它连着现实里真实的人和需要 |
| 可行 | 我足够能把它做出来 | 在我的能力和资源里，这件事跑得动 |

交互：每维一个 1-5 自评滑条，孩子自己拉。小伍在**低分维度**追问一句（如"可行"很低 → "哪一块让你觉得难？"），帮孩子调整议题或调整预期。
产出：责任议题卡 + 五维自评

### 【实感力锻造】

**第3关 · 实感力启动**
目的：用"我关注什么 / 我经历了什么 / 我见证别人什么"三个问题启动实感力，把责任议题回归到真实场景，落到一个人的真实经历里。
方法引导：自己回忆、同伴交流、社区调研、网络浏览。
AI 协作：孩子与小伍对话，小伍不断追问，帮他还原一个有细节、有证据、有深度的故事。
产出：实感故事卡

**第4关 · 问题侦探局**
目的：深挖根源，在深度中找到自己的切入窗口。
追问链：这个问题除了主角还牵涉哪些人？为什么至今没被解决？谁想解决过、做了什么、又为什么没做到？
产出：问题冰山图 + 切入窗口

### 【脑波力启蒙】（更硬）

**第5关 · AI机制拆解局**
目的：从"会用 AI"进阶到"看懂 AI 如何运作、如何影响人"。
内容：
- 人机交互全景：推荐算法与广告应用、视觉识别与智能驾驶、大语言模型与聊天机器人、AI 智能体与画图/创意/编程等工作。
- AI 技术边界：AI 能做什么、不能做什么。
- 议题机制拆解：拆解自己选中的责任议题背后的多重 AI 机制（它是怎么影响/牵引人的）。
产出：议题机制拆解图 + AI能/不能清单

**第6关 · AI共创准备站**
目的：了解人和 AI 的协作流程，掌握负责任使用 AI 的最佳实践。
内容：研究系统提示词 / `claude.md`；每轮测试；模块化；UGC、数据收集等的网络安全考虑；敏感价值观伦理分析（例如心理安全）；等等。
产出：人机协作准备清单

### 【创心力迸发】

**第7关 · 愿景与方法站**
目的：把真实问题转化为可落地的方案设计蓝图。
内容：愿景 → 行动 → ABC 技术画布（A意识唤醒 / B行为干预 / C结果验证）→ Demo 规划 → Effect 效果验证设计。
产出：方案设计蓝图

**第8关 · Demo工坊**（全流程最耗时，重量保留，内部拆成有节奏的序列）
目的：真正把方案构建出来、测出来、审出来。
开发环境：
- 引导文档：安装当前 AI-native、国内可用、儿童青少年友好、性价比高的开发环境。真实交付使用开源解决方案 + 沙箱环境，提前一天告知并装好环境。
- 本站可自动化部署可国内访问的网站（调用 GitHub 等，尽量 minimize 本站技术实现难度）。
内部节奏：搭环境 → 构建 → 自测/找bug/跑边界case → 边改边做责任审查。技术专家辅助（小伍 agent，可随时提问；小伍拟接 API：DeepSeek）。

两个强制 checkpoint（本关校验：各至少完成一次，否则不放行）：
- 🔧 **工程审查按钮**：主动找一次技术指导（小伍/技术专家），就自己的 Demo 问一次——是你主动发起，不是系统塞给你。仅要求一次为硬门槛，之后是否再审交给孩子自己。建议留痕（问了什么、得到什么建议）。
- 🧘 **身体放松按钮**：至少做一次身体感知与放松，系统提供引导，完成即可。（直接扣"身体安全"维度：在最容易久坐上头的构建环节，示范"负责任的开发者也对自己的身体负责"。）

验收取向：一般建议做可演示的 Demo 产品，可用 mock 数据。关键考核解决的问题与方案本身——有用、友好、安全、可持续。
产出：可演示 Demo + 迭代记录 + 责任审查记录（含工程审查、身体放松完成标记）

### 【沟通力绽放】

**第9关 · 影响力**
目的：把作品价值放大，构建三层影响力。
- 真实影响力：愿景未来辐射的人群、解决的社会问题。
- 传播影响力：营销意义的 slogan 设计。
- 持续影响力：商业闭环设计，进入市场可持续发展。
产出：三层影响力方案 + slogan

**第10关 · 小伍创客发布会**
目的：把作品讲清楚、展示出来，完成通关。
内容：录制发布会视频、发布、展示成果，生成作品卡与徽章。
产出：发布会视频、作品卡、徽章

## 六、少年版减负档（12-14 岁，与青年版同构）

差异只落在四个"硬"关，其余关卡与青年版共用。

| 关 | 青年版（15-18） | 少年版（12-14，减负同构） |
| --- | --- | --- |
| 第5关 AI机制拆解 | 六类人机交互全景 + 技术边界 + 议题多重机制拆解 | 认识 3-4 种常见 AI + "AI能/不能做" + 用一个比喻拆解你议题里的 AI 机制 |
| 第6关 AI共创准备 | 系统提示词/`claude.md`、每轮测试、模块化、网络安全、伦理分析 | 简化协作流程（把任务讲清 = Prompt 模板）+ 一条安全铁律 + 一条伦理提醒 |
| 第8关 Demo工坊 | 真开发环境/沙箱/部署/边界case/工程审查（找真人技术专家） | 固定模板 + mock 数据；工程审查简化为"向小伍问一次"；**身体放松保留（强制）** |
| 第9关 影响力 | 真实 × 传播 × 持续三层 + 商业闭环 | 真实影响力（帮到谁）+ 一句 slogan，去掉商业闭环 |

## 七、发布合规闸口（系统层，不进关卡设计）

作品进入官方平台前，由**审核后台 + 红灯机制**强制把关：隐私脱敏、不露脸优先、拦截真实姓名/学校/地址/API Key、家长确认关键节点等。

这道闸口是**系统职责**，与第 8 关的"产品设计层面伦理审查"分工不同：第 8 关审的是"这个产品设计得负不负责任"，发布闸口审的是"这份内容能不能安全公开"。两者不混为一谈。

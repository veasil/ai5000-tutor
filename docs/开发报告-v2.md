## 二、每关功能详述

### 第 1 关 · 小伍风险冒险局（安全力觉醒）

**交互流程**：①选路 → ②自评 → ③答题（占位） → ④复盘（占位） → ⑤收敛

- **选路**：两个大按钮 🎯给我推荐 / 💡我有点子，点子路线额外显示输入框
- **自评**：5 条滑条（1-5），对应身体/心理/社交/经济/数字权益
- **答题 & 复盘**：按要求留为占位区，带跳过按钮继续闯关
- **收敛**：5 类 20 个议题芯片 + 自填框，选满 3 个锁定，生成完成卡含五力分
- **产出**：`{ power_scores, cards_played[], top3_concerns[3] }`

### 第 2 关 · 责任议题锁定（安全力觉醒）

**交互流程**：①回显 → ②五维自评 → ③追问 → ④分析推荐 → ⑤确认

- **议题回显**：三张议题卡（网络欺凌/隐私泄露/算法歧视）
- **五维自评**：3 个议题 × 5 维滑条（共振/责任/原创/嵌入/可行），Tab 切换
- **低分追问**：≤2 时自动弹出追问（每维写死），用户答文本
- **数据分析**：3×5 条形对比图 + 推荐卡（共振×可行最稳者优先）
- **确认**：[就选它] / [我想换一个]，锁定弹窗 → 直接进入第 3 关
- **产出**：`责任议题卡{ 议题, 三议题五维分, 系统推荐, 最终选择 }`

### 第 3 关 · 实感力启动（脑波力启蒙）

**交互流程**：①介绍 → ②调研取材 → ③深度追问 → ④生成故事卡

- **4 调研任务卡**：🧠自己回忆 / 👥同伴交流 / 🏘️社区调研 / 🌐网络浏览
- **采访指南卡**：自动生成 + 复制按钮（clipboard API）
- **安全徽章**：网络浏览卡带 🔴 内容安全约束标识
- **3 轮追问**：细节→证据→深度，写死轮次，不走 LLM
- **故事卡生成**：主角 + 情节 + 证据 + 素材来源，自动汇总
- **产出**：`实感故事卡{ 主角, 情节, 证据, 紎材来源[] }`

### 第 4 关 · 问题侦探局（脑波力启蒙）

**交互流程**：①牵涉了谁 → ②为何没解决 → ③谁试过 → ④冰山图

- **故事回显**：来自第 3 关的主角/情节/证据
- **Step ①**：多标签输入，可加删
- **Step ②**：自由文本框
- **Step ③**：三列网格（谁/做了什么/为什么没成）+ 再加一组按钮
- **Step ④ 冰山图（Hero）**：
  - 完整 SVG 冰山，天空/云层/水面/深洋/气泡动画
  - 3 区域自动填入：水面以上=表象，水面下=牵涉的人，海底=根源
  - 可拖拽切入标记（橙色脉冲圆 + 虚线环），标记跟随显示区域标签
  - 提交后生成 JSON 输出预览 + 庆祝动画
- **产出**：`问题冰山图{ 表象, 水面下[], 根源[], 切入窗口 }`

### 第 5 关 · AI机制拆解局（实感力锻造）

**交互流程**：①人机交互全景 → ②AI 能/不能 → ③拆解我的议题

- **全景浏览**：4 信息块（推荐算法/视觉识别/大模型/AI智能体），配描述
- **AI 能/不能**：左栏 3 张能卡 + 右栏 3 张不能卡，点开看案例
- **拆解作业**：开放文本框 + 两栏动态列表（AI能帮 / AI不能替），实时 JSON 预览
- **提交后**：直接链接进入第 6 关
- **产出**：`{ 议题机制描述(开放), AI能[], AI不能[] }`

### 第 6 关 · AI共创准备站（实感力锻造）

**交互流程**：①~⑤浏览5模块 → ⑥拼清单

- **双栏布局**：左侧模块导航 + 右侧内容区
- **5 模块**：①系统提示词（3条规则）→ ②每轮测试 → ③模块化（3块） → ④网络安全 → ⑤伦理分析
- **每模块**：知识段落 + 作业输入 + 保存按钮
- **进度条**：0/5 → 5/5
- **清单合成器**：协作流程 / 安全项 / 伦理项，自动汇总
- **复制/导出**：clipboard + .txt 文件下载
- **提交后**：直接链接进入第 7 关
- **产出**：`人机协作准备清单{ 协作流程[], 安全项[], 伦理项[] }`

### 第 7 关 · 愿景与方法站（创心力迸发）

**交互流程**：①愿景 → ②ABC画布 → ③Demo规划

- **愿景**：一句话愿景 + AI Action 输入
- **ABC画布**：三格填写（A意识唤醒/B行为干预/C结果验证），中途责任弹窗
- **Demo规划**：要做的Demo + 效果验证 + 可能难点
- **蓝图生成**：验证字段后一键生成，展示完整方案蓝图卡片
- **产出**：`方案设计蓝图{愿景, ABC, Demo规划, Effect}`

### 第 8 关 · Demo工坊（创心力迸发）

**交互流程**：①配环境 → ②自测迭代 → ③提交出URL

- **教学卡**：装Trae国内版 → 喂开工清单 → Vibe Coding 三步图文
- **自测区**：迭代记录 + 边改边责任审查弹窗（2个确认复选框）
- **2 强制 Checkpoint**：
  - 🔧 工程审查：点开小伍对话（模拟扣1能量），一次硬门槛
  - 🧘 身体放松：CSS 呼吸动画（3次吸气/呼气周期，圆扩缩）
- **提交**：模拟上传 → 生成假 URL → 显示完成卡
- **产出**：`{ Demo_URL, 迭代记录[], 责任审查记录, checkpoint:{工程✓,身体✓} }`

### 第 9 关 · 影响力（安全力觉醒）

**交互流程**：①真实 → ②传播 → ③持续 → ④多方 → ⑤生成方案

- **三层影响力**：真实（帮到谁+解决什么）→ 传播（slogan）→ 持续（商业闭环）
- **多方视角**：4格利益相关方（用户/家长/平台/社会）
- **生成**：汇总三层 + 多方 → 影响力方案卡片
- **产出**：`三层影响力方案{真实, 传播:slogan, 持续:商业闭环}`

### 第 10 关 · 创客发布会（沟通力绽放）

**交互流程**：①演讲稿 → ②录制 → ③作品卡 → ④安全审核 → ⑤发布

- **脚本卡**：自动填充模板 "我看到__所以我做了__它能帮__"
- **模拟录制**：计时器 + 红点闪烁 + 开始/停止按钮
- **作品卡**：自动汇总议题+Demo+影响力+5力图标+日期
- **合规闸口**：4项系统检查（隐私/不露脸/拦截真实信息/家长确认）
- **发布 + 徽章**：5力徽章 + 通关徽章顺序解锁 + CSS 彩纸动画
- **产出**：`{视频, 作品卡, 徽章[]}`

## 三、后端架构摘要

### API 设计（docs/api-design.md）

覆盖 9 大模块 30+ 端点：

| 模块 | 核心端点 | 说明 |
|------|---------|------|
| 认证 | POST /api/auth/anonymous | 匿名 child session |
| Journey | start / get / advance / save | 状态机驱动闯关 |
| Level | POST /api/journey/[id]/level/N | 十关数据独立存储 |
| AI Tutor | POST /api/tutor/[journeyId] | SSE 流式输出 |
| 安全 | POST /api/safety/check | 红灯检测 |
| 作品 | submit / list / review | 双门发布（运营+家长） |
| 卡牌 | GET /api/cards?ageStage | 按年龄段获取 |
| 能量 | deduct / supplement | 伍力能量值系统 |
| 家长 | children / confirm | 家长确认闸口 |

### 状态机（src/lib/journey/state-machine.ts）

- 五力映射：安全(L1,2,9) → 脑波(L3,4) → 实感(L5,6) → 创心(L7,8) → 沟通(L10)
- 不可跳关：`advanceLevel` 校验前置关卡
- 第9关强制安全检查：`publishStatus` 仅在 L9 通过后可从 draft → reviewing
- 完成关卡记录：`completedLevels[]` 数组

### 十关配置（src/lib/journey/level-configs.ts）

每关定义：名称、五力类别、模板类型、输出字段、Zod 校验规则、解锁条件
- L1: ≥6答题 + 3议题
- L2: 锁定1议题 + 3议题自评完成
- L3: 主角+情节+≥1证据
- L4: 三层填齐 + 切入窗口
- L5: ≥1机制描述 + 能/不能各≥1
- L6: 5模块完成 + 合成清单
- L7: ABC三格满 + 1 Demo
- L8: 出URL + 2 checkpoint + ≥1迭代
- L9: 3层各一段 + slogan
- L10: 录制 + 过闸口 + 作品卡

### TypeScript 类型（src/types/index.ts）

- Zod schema 覆盖所有十关的输出结构
- `ActionResult<T>` 统一返回格式
- 20 个 ErrorCode 常量
- `LevelOutputSchemaMap` 类型安全的每关访问

### 数据库（prisma/schema.prisma）

核心表：Parent / Child / Journey / JourneyLog / Conversation / Work / Badge / RiskCard / DemoTemplate / EnergyLog / ParentConfirmation / SystemSetting

## 六、技术架构

- **前端**：纯 HTML + CSS + Vanilla JS，无框架，约 321KB
- **设计系统**：styles.css 定义 CSS 变量（cream/ink/primary/blue/line/danger），4 字体族（serif/fun/pixel/sans），描边阴影风格
- **小伍悬浮窗**：widget.js 注入所有页面，桌面端可拖拽，写死答疑 + 自由输入
- **动画**：IntersectionObserver reveal、CSS keyframes（呼吸、脉冲、冰山气泡、彩纸）
- **后端**：Next.js 15 App Router + Prisma ORM + PostgreSQL + Redis + Anthropic SDK
- **状态机**：线性解锁 + L9 强制安全检查 + 双门发布闸口

## 第 1 关 · 小伍风险冒险局

**类型**：混合（卡牌答题器 + 复盘接计分系统）。**注入**：无。

**① 入口选择**
小伍："先选一条路——" 　两个大按钮：
- **[🎯 给我推荐]** 副文案"我不太确定，帮我挑"
- **[💡 我有点子]** 副文案"我已经想到要做什么了"

**② 了解度自评**（两条路都要）
小伍："这五种风险，你各自了解多少？拉一拉～"
五条滑条（1 完全不懂 – 5 很了解）：身体安全 / 心理安全 / 社交安全 / 经济安全 / 数字权益。
（点子路线额外：输入框占位"用一句话说说你的点子…"）

**③ 卡牌答题器**
小伍："来帮小伍闯几关，看看你的直觉～" 引擎按 `适龄=版本 + 低了解/高兴趣域` 推 6~7 张。
每张卡：
- 顶部 `引导语`（写死，来自卡库）如"身体安全风险预警，如何助力小伍通关？"
- `事件描述` 正文（写死）
- 三个选项按钮 **A / B / C**
- 选完弹**反馈卡**（写死）：显示所选项五力增减（如"安全力 +1　实感力 +1　沟通力 +1"）+ `五力理由` + `结果`。
- 底部小链接："都不满意？**帮小伍想个 D →**"（点开 = 共创D选项输入框；**D 的点评走答疑/扣能量**）

**④ 复盘**（接计分系统现成功能）
小伍："几关下来，看看你最在意什么 👇" → 展示五力雷达 + 一句写死解读模板"你在【X 风险】上的反应最强烈"。

**⑤ 收敛产出**
小伍："那——最让你放不下的，是哪 3 个问题？"
议题清单（可点选）+ 自填框"自己写一个…"。选满 3 个 → **[锁定我的 Top 3]** → 解锁第 2 关。

**产出**：`{ power_scores, cards_played[], top3_concerns[3] }`　**判定**：≥6 张答题 + 3 个问题。**版本差异**：仅卡池。

## 第 2 关 · 责任议题锁定

**类型**：功能对话（写死）。**注入**：`Top3`。

**① 议题回显**
小伍："你锁定了这 3 个问题，我们来挑一个真正想做的。" → 三张议题卡横排。

**② 三议题五维自评**
小伍："先别急着选。对每个问题，问问自己这五句——"
对**每个议题**呈现五条"我足够…"滑条（1–5）：
- 共振："我足够被它触动"
- 责任："我足够愿意为它负责"
- 原创："我足够想用自己的方式做"
- 嵌入："它足够连着现实里真实的人"
- 可行："我足够能把它做出来"

**③ 低分追问**（写死，逐维触发）
某维 ≤2 时小伍固定追问一句，例如：
- 可行低："这一块哪里让你觉得难？是不会做，还是没资源？"
- 共振低："这个问题，是你真的在意，还是觉得应该选它？"
用户答（文本，落库，不走 LLM）。

**④ 数据分析 + 推荐**
小伍："都填完啦！我把三个摆一起看看 👇"
- 数据面板：三议题五维对比（雷达/条形）。
- 推荐卡（写死规则："共振×可行"最稳者优先）：
  > 🐝 我的建议是【议题 B】。
  > 它是你**又在意、又做得动**的那个——共振 5、可行 4。
  > 想做但太难，容易半路卡住；能做但不在意，容易没劲。B 最平衡。

**⑤ 确认**
按钮 **[就选它]** / **[我想换一个]**（换 = 回第 1 步重挑）。确认 → 锁定 → 解锁第 3 关。

**产出**：`责任议题卡{ 议题, 三议题五维分, 系统推荐, 最终选择 }`　**判定**：锁定 1 个 + 三议题自评完成。**版本差异**：无。

**② 四种调研方法任务卡**（多选，写死脚手架）

| 任务卡 | 点开后（写死） | 录入 |
| --- | --- | --- |
| 🧠 自己回忆 | "闭上眼想一想：①最近一次是什么时候？②当时你身体/心里什么感觉？③谁在场？" | 文本框 |
| 👥 同伴交流 | 生成**采访提纲卡**："问问同学：你遇到过 {议题} 吗？当时怎么办的？后来呢？"（可复制/截图带走） | "同伴说了什么…" |
| 🏘️ 社区调研 | 生成**调研模板**："去观察/问 2-3 个人：这个问题在你身边发生过吗？谁受影响最大？" | 观察记录框 |

**③ 固定追问**（写死轮次，不走 LLM）

- 第1轮（细节）："能再具体点吗？那是在哪、什么时候？"

**④ 提交**
小伍："一个有血有肉的故事就立起来了！" → **[生成我的实感故事卡]** → 解锁第 4 关。

**产出**：`实感故事卡{ 主角, 情节, 证据, 素材来源[] }`　**判定**：主角+情节+≥1 证据。**版本差异**：无（少年版不减码）。

## 第 5 关 · AI机制拆解局

**Step ① 全景浏览**（图文/短视频块，逐屏往下读）

- **AI 能/不能清单**：两栏各"就我的议题，AI 能帮：__ / AI 不能替：__"
- **[提交我的拆解]** → 解锁第 6 关。

**产出**：`{ 议题机制描述(开放), AI能[], AI不能[] }`　**判定**：≥1 机制描述 + 能/不能各≥1。**版本差异**：有（见少年版）。

## 运营入口

**类型**：运营 / 管理后台。**使用者**：训练营运营人员。**进入**：运营账号登录（权限隔离）。无小伍人格。

| 模块 | 用途 | 关键操作 |
| --- | --- | --- |
| 用户管理 | 查看用户、身份、绑定家长、闯关进度 | 搜索 / 筛选；查看单个档案 |
| **开营管理** | 创建一期创客营 → 批量开通成员 | 新建营期 → 导入名单 → **批量设为「创客营成员」+ 发放当日 / 期限伍力能量值** |
| **申请入营处理** | 处理孩子 / 家长的"申请入营"请求 | 审批通过 → 开通成员身份 |
| **补充能量** | 响应"补充能量"请求 | 给指定用户手动增补伍力能量值 |
| **资产管理** | 管理第 8 关提交、EdgeOne 部署的作品 | 查看 Demo URL / 状态；上下线、管理用户资产 |
| **内容审核后台（红灯机制）** | 发布闸口的人工复核队列 | 查看命中项（隐私 / 露脸 / 真实信息 / 敏感）→ 放行 / 打回并附理由 |
| 数据看板 | 运营概览 | 各关完成率、能量消耗、活跃营期（🟡指标待定） |

**开营发放（对应"开营时给当日 VIP"）**
新建营期 → 设成员有效期（当日 / 本期）→ 导入参营名单 → 一键批量开通成员 + 发放初始伍力能量值。

**审核后台流转（发布闸口）**
```
孩子点发布 → 系统自动检测 → 命中红灯项 → 进运营审核队列
 → 运营复核：放行 / 打回（附修改理由回给孩子）
 → 放行 且 家长确认通过 → 正式发布
```
> 边界：发布闸口的"自动检测"是系统能力，"人工复核"是运营操作；**家长确认与运营审核是两道独立关卡，都通过才发布**。

**闭环对照**：全局外壳的"申请入营 / 补充能量"弹窗 → 落到运营入口的「申请入营处理 / 补充能量」；家长页也有申请入营入口。三处指向同一运营通道。
